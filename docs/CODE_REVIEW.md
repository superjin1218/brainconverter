# 푸시 전 코드 검토

검토일: 2026-09-27. CodeRabbit 없이 직접 검토했습니다. 기준 커밋은 `69b9391`이며 검토 대상은 Muse 단일 호출·Supabase 회원 승인·로그인 첫 화면·비밀번호 조건 변경과 함께 저장하는 작업 트리입니다.

## 검토 결과와 보완

검토 범위에서 미해결된 푸시 차단 문제는 발견하지 않았습니다. 아래 항목을 확인하고 문서·저장 설정을 보완했습니다.

- 서버는 Supabase에서 신원·이메일 인증·승인 상태를 확인한 뒤 변환합니다. 미로그인·미승인 요청은 모델을 호출하지 않습니다. 운영자 기능은 별도로 권한을 검사합니다.
- 가입 metadata는 이름만 사용합니다. DB의 승인 상태·운영자 권한을 가입 요청으로 바꿀 수 없습니다. DB 테이블은 일반 회원에게 직접 CRUD를 허용하지 않고 변환 예약·저장 함수는 서버 전용입니다.
- 동일 Origin·요청 헤더, HttpOnly·운영 Secure 쿠키, 요청 본문 크기 제한, 안전한 오류 응답을 확인했습니다. 로컬 키 설정 API는 개발 환경의 loopback 요청만 받으며 운영 환경에는 등록하지 않습니다.
- Muse 모델과 Meta 제공자를 고정하고 호출은 1회로 제한합니다. 오류 후 자동 모델 재시도·대체 제공자·모의 결과 반환은 없습니다. Contributor 동의를 서버에서도 검사합니다.
- PostgreSQL 트랜잭션에서 회원·전체 사용량과 동시 요청을 제한합니다. 동일 입력·요청 ID의 완료 결과는 재사용하며 회원별 결과 접근을 확인합니다.
- 앱의 비밀번호 최소 8자 검사와 안내를 제거했습니다. 숫자 비밀번호 전달을 대역 Auth로 검증했습니다. 실제 Supabase는 최소 6자·문자 조합 요구 없음으로 확인했으며 계정 생성·비밀번호 변경은 하지 않았습니다.
- Git 푸시로 배포하지 않도록 `vercel.json`에 `git.deploymentEnabled=false`를 추가했습니다. 기존 Vercel의 빌드 중지 설정도 유지합니다. 현재 공급자·회원 화면과 맞지 않는 이전 클라우드 배포 workflow는 `if: false`로 비활성화했습니다. 이전 scripts·Gateway는 과거 구성의 기록이며 현재 배포용으로 사용하지 않습니다. [Vercel 공식 설정](https://vercel.com/docs/project-configuration/git-configuration#turning-off-all-automatic-deployments).
- `.env.*`와 `.vercel/`을 Git·컨테이너 빌드 대상에서 제외했습니다. Git에는 빈 키 예시 파일만 포함합니다. 키·JWT·비밀키 패턴 검사에서 두 개의 명시적 테스트 대역 키만 발견했습니다. README·개발 안내·현재 상태 문서를 최신 구조와 비밀번호 정책에 맞췄습니다. 로그인·회원가입 화면의 요청된 가입 절차 설명도 제거했습니다.

## 검증

| 검증 | 결과 |
| --- | --- |
| Python + 임시 PostgreSQL | 258개 통과, 건너뛴 테스트 없음 |
| 프런트 상태 | 16개 통과 |
| 이전 Gateway | TypeScript 검사·테스트 10개·빌드 dry-run 통과 (Node.js 22) |
| Ruff / diff 공백 검사 | 통과 |
| 오프라인 회귀 | 100/100 |
| 실제 모델 호출 | 0회 |

Auth·모델 테스트는 응답 대역이며 DB 테스트는 외부 Supabase가 아닌 임시 PostgreSQL입니다. 모의 평가의 통과율은 Muse 해석 정확도가 아닙니다. 현재 기본 Node.js 18로 이전 Gateway 테스트를 실행하면 실패하므로 `gateway/package.json`과 CI에 명시된 Node.js 22 이상을 사용합니다.

## 운영 전 남은 검증

SMTP, 실제 운영자 가입·인증·권한 부여, Gateway 키 또는 Vercel OIDC·크레딧 확인, 실제 Muse 소수 사례, 배포 환경의 가입·승인·변환 흐름과 BRAIN 실행은 별도 확인이 필요합니다. 코드 검토·오프라인 테스트만으로 이 항목의 성공을 보장하지 않습니다. 절차는 [설정 문서](VERCEL_SUPABASE_SETUP.md)와 [모델 검증 범위](MODEL_COST_AND_VALIDATION.md)를 따릅니다.
