# 운영 기준

## 기본 한도

- 사용자당 2회/분
- 사용자당 20회/일
- 서비스 전체 동시 하네스 작업 2개
- 전략 입력 최대 2,000자
- agent당 모델 출력 최대 256토큰

## 월 1,000회 예산

6-agent 호출이 agent당 입력 900토큰, 출력 180토큰을 사용한다고 가정하면 GPT-5 mini 모델 비용은 약 `$3.51`입니다. Cloud Run을 scale-to-zero로 두고 Cloudflare 무료 구간을 사용하면 월 예산 상한 `$10`으로 시작할 수 있습니다.

## 관찰 지표

- 성공 응답률: 목표 98% 이상
- p95 응답시간: 목표 45초 이하
- JSON/schema/compile 거부율
- 사용자별·전체 요청 수
- 모델 입력·출력 토큰과 추정 비용

## 운영 중단 조건

- 월 예산의 80% 도달
- 모델 공급자 오류율 10% 이상
- 검증되지 않은 표현식 노출 발견
- API 키 또는 전략 원문이 로그에 기록된 정황 발견
