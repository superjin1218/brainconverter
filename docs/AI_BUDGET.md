# GPT 비용 집계와 20,000원 예산 한도

관리자 화면은 사이트 전체 GPT 호출 시도·입출력 토큰·토큰 기준 예상 비용(USD)·예산 예약액(KRW)을 구분합니다. 관리자 본인의 월·일 사용횟수는 전략 입력창에서 따로 확인합니다.

## 토큰 비용 계산

[GPT-5.4 mini 공식 요금](https://developers.openai.com/api/docs/models/gpt-5.4-mini)을 2026-09-28 확인했습니다. Standard 기준 일반 입력 $0.75/M, 캐시 입력 $0.075/M, 출력 $4.50/M입니다. `backend/app/openai_policy.py`가 요금과 계산식을 소유합니다.

```text
예상 USD = ((전체 입력 − 캐시 입력) × 0.75 + 캐시 입력 × 0.075 + 출력 × 4.50) / 1,000,000
```

저장은 각 항목을 마이크로달러 단위로 올림한 정수입니다. 입력 828·출력 74·캐시 0이면 $0.000954입니다. 호출당 고정 요금이 아닙니다. 최종 청구액은 OpenAI에서 확인합니다.

`brain_finish`는 완료된 GPT 응답의 `usage`를 영구 예약 원장 `private.brain_ai_charges`에 복사합니다. 결과 JSON의 24시간 정리나 회원·작업 삭제 후에도 비용 합계를 유지합니다. 실패·타임아웃·사용량 누락 건은 0원으로 확정하지 않고 **비용 미확인** 건수로 구분합니다. 이 건들의 실제 비용은 OpenAI에서 확인해야 합니다.

## 예산 예약과 차단

실제 GPT 시도 직전에 34원을 예약합니다. 직렬화 요청 16,000바이트·최대 출력 1,024토큰의 보수적인 $0.017 상한과 내부 환산 2,000원/USD를 적용한 값입니다. 실제 환율이나 실제 청구 요금이 아닙니다.

현재 집계 기간의 예약액이 20,000원을 넘는 새 요청을 차단합니다. 0원부터 최대 588회 시도할 수 있습니다. 실패·월 변경·회원 삭제로 예약액을 돌려주지 않습니다. 중복 요청 ID는 한 번만 예약하며, DB 오류 시 GPT 호출을 시작하지 않습니다. DB 전역 잠금으로 동시 요청을 제어합니다.

회원별 월 50회·일 20회·분당 2회, 사이트 월 1,000회·동시 20건 제한도 유지합니다. 다른 앱에서 같은 키를 사용한 비용·유료 CLI 평가·호스팅·세금 등은 이 집계에 포함되지 않습니다.

## 2026-09-28 사용자 요청 초기화

`202609280005_gpt_usage_reset.sql`을 처음 적용하는 시점에 예산 예약액을 0으로 만들고 승인된 관리자들의 월·일 사용횟수를 새로 계산합니다. 일반 회원의 한도 기록과 사이트 전체 월 한도는 유지합니다. 진행 중인 변환이 있으면 적용을 중단합니다.

과거 작업과 예약 원장은 삭제하지 않습니다. 이전 누적액과 예약 건수는 `private.brain_accounting_reset`에 보존하며, 새 비용 집계는 여기에 기록한 시작 시각 이후만 포함합니다. 같은 마이그레이션을 다시 실행하거나 다시 배포해도 초기화는 반복되지 않습니다. OpenAI 자체의 사용량·청구 내역은 바뀌지 않습니다.

운영 DB에는 기존 004 마이그레이션 이후 005를 적용합니다. 새 관리자 비용 표시는 코드 재배포 후 반영됩니다. `make preflight-openai`로 005 적용 여부를 읽기 전용으로 확인할 수 있습니다.
