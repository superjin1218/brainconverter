# 누적 AI 비용 20,000원 자동 중지

2026-09-27 구현·검증. Vercel + Supabase 회원 모드의 실제 Muse 변환에 적용합니다. Q-Lab Supabase에 [003 마이그레이션](../supabase/migrations/202609270003_ai_budget.sql)을 적용했고 한도 20,000원·누적 0원·익명/회원 예약 금지·서버 전용 예약 권한을 확인했습니다. 앱 코드는 다음 배포부터 적용됩니다.

## 계산 방법

실제 모델 호출 전에 요청마다 **4원**을 DB에 예약합니다. 누적 예약액 20,000원에서 새 유료 변환을 중지하므로 최대 5,000회 시도입니다. 기존 사이트 월 1,000회·회원 월 50회 제한도 유지합니다. **월 변경 시 초기화되지 않는 누적 한도**입니다.

현재 Contributor 가격은 입력 100만 토큰당 $0.10, 출력 $0.20입니다. 시스템 지침·스키마를 포함한 요청 JSON은 16,000바이트 이내, 출력 전체는 최대 1,024토큰입니다. 이 제한과 요금을 바탕으로 요청당 $0.002의 보수적 허용액에 2,000원/USD의 환산 여유를 적용했습니다. [Vercel 모델·요금](https://vercel.com/ai-gateway/models/muse-spark-1.3-contributor).

이 금액은 공급자 청구서와 다릅니다. 실제 사용료가 적어도 예약액은 유지하므로 실제 청구 2만 원보다 먼저 중지될 수 있습니다. 환율·세금·수수료·모델 가격 변경에 대한 절대 청구 보장은 아니며 가격이나 요청 상한을 바꾸면 허용액도 다시 검토해야 합니다.

## 중복·실패·동시 요청

- 슬롯을 확보한 실제 Muse 시도만 예약합니다. 대기 확인·완료 결과 재사용·모의 변환은 금액을 예약하지 않습니다.
- 실패하거나 청구 여부가 불명확해도 예약액을 돌려주지 않습니다.
- DB가 없거나 응답이 불명확하면 유료 호출을 시작하지 않습니다.
- 동시 요청도 같은 PostgreSQL 전역 잠금에서 예약합니다. 동일 ID는 한 번만 예약하며 다시 유료 호출하지 않습니다.
- 회원 삭제·결과 정리·월 변경·마이그레이션 반복 실행으로 금액이 초기화되지 않습니다.

임시 PostgreSQL에서 누적 19,996원의 20개 동시 예약 중 1개만 허용되고 19개는 차단되는 것을 확인했습니다. 익명·회원의 직접 변경/예약 차단과 동일 ID 중복 방지도 검증했습니다.

## 관리와 적용 범위

운영자 **설정 → 회원 승인 관리**에서 누적 금액·중지 상태를 확인합니다. 일반 회원에게 설정 창·초기화 버튼은 없습니다. 프로그램은 한도를 스스로 재개하지 않습니다.

이 제한은 **이 앱의 Supabase 회원 경로를 거친 신규 Muse 시도**만 계산합니다. 과거 호출, 같은 키를 쓰는 다른 앱·CLI·모델 평가, 로그인 없는 개발 모드, Vercel·Supabase·SMTP 기본료는 포함하지 않습니다.

Vercel AI Gateway 키라면 키 전용 예산을 예컨대 **$8, 자동 갱신 없음**으로 추가 설정할 수 있습니다. 공급자 예산은 요청 시작 시 확인하므로 진행 중인 동시 요청으로 초과할 수 있어 앱 DB 제한과 함께 사용합니다. 키 발급처가 확인되지 않아 공급자 예산은 설정하지 않았습니다. [Vercel 예산 안내](https://vercel.com/docs/ai-gateway/observability-and-spend/budgets).

이번 검증의 실제 Muse 호출은 0회입니다.
