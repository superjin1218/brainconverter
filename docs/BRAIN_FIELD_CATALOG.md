# BRAIN 필드 카탈로그 운영

AI는 계정에서 실제로 조회한 필드 후보에서만 ID를 선택합니다. 검색어 정리 단계는 자연어 개념을 영문으로 정리하며 필드 ID나 코드를 만들지 않습니다. OpenAI 임베딩으로 설명이 가까운 후보를 찾고, GPT가 후보 ID·자료형·설명을 보고 측정 계획을 만듭니다. 검색 후보는 최대 12개와 실제 기본 필드 6개로 제한합니다. 지표명과 필드명을 연결하는 고정 표는 없습니다.

## 준비 및 갱신

```bash
.venv/bin/pip install -r deploy/requirements.lock
.venv/bin/python scripts/refresh_brain_catalog.py \
  --credentials-file /path/to/private-wq.env --all-datasets \
  --fields-per-dataset 50
.venv/bin/python -m scripts.check_production_config --env-file
```

비공개 WQ 파일은 `.env.wq.example`의 빈 항목을 참고해 `WQ_EMAIL`·`WQ_PASSWORD`를 설정하고 권한을 600으로 유지합니다. 실제 값은 터미널 출력이나 Git에 넣지 않습니다. OpenAI 키는 기존 `.env.local` 또는 `OPENAI_API_KEY`에서 읽습니다. 갱신은 공식 WQ API의 `/data-sets`에서 계정 데이터셋을 발견하고 각각의 `/data-fields`를 조회하며 `/operators`도 확인합니다. 전역 `/data-fields`는 10,000행에서 잘려 알파벳 뒤쪽 필드가 빠질 수 있어 사용하지 않습니다. 위 명령은 데이터셋마다 첫 50행을 가져와 분야를 골고루 포함하는 제한된 카탈로그를 만듭니다. 전체 페이지를 읽으려면 `--fields-per-dataset 0`을 사용합니다. API 자체가 제한하는 범위를 넘는 완전성을 주장하지 않습니다. 필요한 데이터셋은 `--datasets id1,id2`로 지정하거나 기존 CSV의 `dataset_id` 열을 `--seed-catalog`로 읽을 수 있습니다. 기본 가격·거래량 6개 필드가 없는 스냅샷은 운영에서 거부합니다. 사용자 지정 데이터셋에는 `pv1`도 포함하세요. 같은 계정·범위에서 직접 확보한 신뢰된 스냅샷을 합칠 때만 `--include-snapshot /path/to/catalog.json`을 명시합니다. 기존 스냅샷에 포함된 필드는 재조회 전까지 그 시점의 메타데이터입니다.

기본 범위는 EQUITY/USA/TOP3000/Delay 1입니다. 다른 Universe·Delay는 `--universe`와 `--delay`로 갱신합니다. 범위별 색인은 `current.json`에 따로 보관됩니다. 지역 변경은 현재 갱신 CLI에서 지원하지 않습니다.

목록과 색인은 Git에서 제외한 `data/brain_catalog/`에 저장합니다. `BRAIN_CATALOG_DIRECTORY`로 경로를 지정할 수 있습니다. 필드 목록·벡터의 SHA-256을 검증하며 완성된 스냅샷만 원자적으로 활성화합니다. 메타데이터만 재사용해 임베딩을 다시 만들 때는 `--reindex-existing`을 사용합니다. 갱신 후 서비스 재시작으로 프로세스 캐시를 비웁니다. 이 명령은 회원·작업·예산 DB에 쓰지 않으며 시뮬레이션이나 알파 제출도 하지 않습니다.

## 비용과 검증 범위

갱신 시 모든 설명을 `text-embedding-3-small`(384차원)로 색인하며 OpenAI 비용이 발생합니다. 운영 변환은 영문 검색어 정리 1회(GPT-5.4 mini, none, 출력 최대 128토큰), 임베딩 검색 1회, 측정 계획 생성 1회(GPT-5.4 mini, none, 출력 최대 1,024토큰)를 실행합니다. 자동 유료 재시도나 다른 모델 전환은 없습니다. 요청 UTF-8 바이트 수로 입력 토큰을 보수적으로 상한 계산하고, 검색·임베딩의 최대 비용을 먼저 차감한 나머지 안에서 후보 수와 생성 출력 한도를 줄입니다. 기존 17,000 microUSD/34원 예약과 누적 한도를 유지합니다. 색인 갱신 CLI 비용은 회원 변환 예약과 별개입니다.

응답 스키마의 필드·비교 필드 enum과 서버 검증에 동일한 후보를 사용합니다. 조건식 속 이름도 검사합니다. 짧은 입력은 원문의 독립 절을 근거 enum으로 제공해 카탈로그 설명을 원문으로 오인하거나 여러 조건이 담긴 전체 문장을 중복 인용하지 않도록 돕습니다. 긴 입력도 서버에서 실제 원문 위치와 중복을 검사합니다. VECTOR는 `vec_avg` 후 MATRIX용 연산을 적용하며, 연산자도 카탈로그에서 확인합니다. 데이터셋도 모델에 알려 서로 다른 출처의 상대 비교에는 비율을 우선합니다. 비율을 순위화할 때는 결과를 바꾸지 않는 -1을 생략해 불필요한 단위 경고를 피합니다. 명시적 차이 연산에는 여전히 호환되는 단위가 필요하며 모든 필드의 단위 표기를 로컬에서 완전히 검증하는 것은 아닙니다. 지원하지 않는 자료형은 후보에서 제외합니다. 괄호·공백이나 인용문 바깥에 붙인 따옴표만 다른 원문 인용은 원래 위치로 연결해 허용하지만 단어·숫자·선호 방향 변경이나 근거 중복은 계속 차단합니다.

이 검사는 임의 ID와 자료형 오류를 막습니다. 의미 검색의 완전성, 원문 해석의 모든 의미, 모든 종목의 데이터 커버리지, 다른 계정의 권한이나 수익성까지 보장하지 않습니다. 운영 기본 목록이 준비되지 않으면 회원 작업·예산 예약 전에 중단합니다. 실행 기록은 별도의 실제 WQ 시뮬레이션으로 확인합니다.
