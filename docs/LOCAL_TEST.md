# 로컬 실행과 Muse 키 연결

## 1. 실행

프로젝트 폴더에서 처음 한 번 `make install`, 이후 `make dev`를 실행합니다.

```bash
make dev
```

<http://127.0.0.1:8080>을 엽니다. 포트 사용 중 오류가 나면 이미 켜진 서버를 사용하거나 그 서버의 터미널에서 Ctrl+C로 종료한 뒤 실행합니다.

이 명령은 **로그인부터 표시하는 회원 사이트 모드**입니다. 로그인한 적이 없으면 로그인/회원가입 화면, 로그인했지만 승인되지 않았으면 승인 대기 화면, 승인된 회원이면 변환 화면이 나옵니다. 기존 로그인 세션이 유효하면 승인 상태 확인 후 바로 이용할 수 있습니다.

Supabase 설정은 Git에서 제외된 `.env.local`에서 읽습니다. [설정 예시](../.env.local.example)를 참고하세요. 현재 이 컴퓨터에는 Q-Lab 프로젝트 URL·공개 키만 연결했으며, 서버 Secret·AI 키는 이 파일에 넣지 않았습니다. 설정이 없으면 로그인 화면을 유지하고 설정 미완료를 알립니다. 일반 회원의 이메일 인증에는 SMTP 설정이 필요합니다.

로그인 없이 코드 화면만 확인하는 모의 개발 실행은 별도 명령입니다.

```bash
make dev-mock
```

`make dev`와 동시에 같은 포트에서 실행하지 않습니다. 모의 결과는 미리 정한 규칙이며 AI 품질 검증이 아닙니다. `AUTH_MODE=none`은 개발에서 명시적으로 선택할 때만 허용되며 운영에서는 차단합니다.

## 2. 실제 모델 키

이번 버전은 OpenAI 키를 사용하지 않습니다. [Vercel AI Gateway](https://vercel.com/docs/ai-gateway/authentication-and-byok/authentication)에서 발급한 키가 필요합니다. 기존 OpenAI 키는 자동으로 이전하지 않습니다. Meta·OpenRouter에서 발급한 키를 이 설정 창에 넣어도 현재 Gateway 연결에 사용할 수 없습니다.

아래 설정 창은 승인된 회원의 변환 화면 또는 `make dev-mock` 개발 화면에서 표시됩니다. 회원 모드의 실제 변환에는 사용량·결과 저장을 위한 Supabase 서버 Secret도 필요합니다.

1. 오른쪽 위 **설정**을 누릅니다.
2. **Vercel AI Gateway 키**를 입력하고 **키 연결**을 누릅니다.
3. 키 설정됨 표시를 확인하고 설정 창을 닫습니다.
4. Contributor의 학습 활용 안내를 읽고 동의한 뒤 간단한 전략을 변환합니다.

키 연결 자체는 모델을 호출하지 않습니다. 실제 키 유효성과 모델 응답은 첫 변환에서 확인됩니다. 키는 로컬 서버 메모리에만 보관하며 브라우저 저장소·파일·Git에 저장하지 않습니다. 서버 재시작(자동 reload 포함) 또는 연결 해제 시 지워집니다.

모델은 `meta/muse-spark-1.3-contributor`로 고정하며 변환당 요청은 한 번입니다. 오류에도 자동 모델 재시도나 다른 모델 전환을 하지 않습니다. 출력 상한은 1,024토큰입니다. 요청 실패 시 화면에 표시한 인증·크레딧·권한·속도 제한 원인을 확인한 뒤 직접 다시 시도합니다.

Contributor는 입력 전략과 모델 응답을 Meta의 모델 학습에 사용하는 조건이 있습니다. 비공개 전략을 입력하기 전에 확인하세요. 2026-09-27 확인 요금: 입력 100만 토큰당 $0.10, 출력 $0.20. 실제 청구는 사용량·계정 조건에 따릅니다. [Meta 요금·조건](https://dev.meta.ai/docs/pricing-rate-limits), [Vercel 모델](https://vercel.com/ai-gateway/models/muse-spark-1.3-contributor).

## 3. 회원 기능

[Vercel·Supabase 설정 문서](VERCEL_SUPABASE_SETUP.md)의 DB·Auth·SMTP·운영자 설정을 마칩니다. `make dev`의 로컬 주소는 `http://127.0.0.1:8080`으로 고정하며 같은 주소로 접속하세요. 서버 Secret이 필요하면 `.env.local`에 사용자가 직접 추가한 뒤 서버를 재시작합니다. 운영자 가입 시 비밀번호는 사용자가 화면에서 직접 입력합니다. 키 값은 채팅·명령 기록·Git에 남기지 마세요.

## 4. 결과의 의미

FASTEXPR와 12개 설정을 생성하고 원문의 조건 보존 여부를 검사합니다. 수익률·성과를 계산하거나 BRAIN에서 시뮬레이션하지 않습니다. 생성한 결과를 BRAIN에 옮겨 Simulate로 실행 여부와 성과를 별도로 확인합니다.

여러 사례의 오프라인 검증은 [평가 안내](../evals/README.md)를 따릅니다. 실제 모델 평가는 유료이며 기본 실행에 포함하지 않습니다.
