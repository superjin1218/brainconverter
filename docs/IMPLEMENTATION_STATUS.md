## 2026-09-26 추가 검증 및 변경

### 변환 실패 수정 및 검증

- 사용자가 연결한 키로 실제 변환을 한 번 시도했으나 HTTP 503으로 실패했습니다. 기존 구현이 공급자 원인을 버려 인증·잔액·요청 형식 중 무엇이었는지는 확인되지 않았습니다. 아래 과거 기록의 '실제 API 미호출'은 이 시도 이전 상태입니다.
- 안전한 오류 분류를 추가하여 인증·권한·잔액·지출/사용/속도 제한·잘린 응답 등을 구분합니다. 키·전략·공급자 원문 오류를 응답이나 로그에 노출하지 않습니다.
- 첫 해석이 성공한 경우에만 나머지 5개를 호출합니다. OpenAI 5xx만 최대 한 번 재시도하며 인증·잔액·요청 형식 오류에는 재시도하지 않습니다.
- 화면이 변환 직전 연결 상태를 확인하고, 확인 이후 모드가 바뀌어도 서버가 409로 차단합니다. 서버 재시작으로 사라진 키를 모의 결과로 대체해 보여주지 않습니다.
- 원문에 명시한 순위가 모델 해석에서 빠지면 거절합니다. '최근 5일 동안 종가가 많이 하락한 종목일수록 높은 순위를 부여한다.'의 올바른 해석에서 `rank(-ts_delta(close, 5))`와 12개 기본 설정이 생성됨을 오프라인으로 확인했습니다.
- 수정 후 Python **201개**, 프런트 상태 회귀 **7개**, Ruff 및 diff 검사가 통과했습니다. 이 검증은 외부 API 대신 응답 대역을 사용했습니다.
- 사용자가 키를 재연결한 뒤 Chrome에서 같은 단순 전략을 다시 변환했습니다. 첫 요청에서 OpenAI **`credit_balance_exhausted`(API 크레딧 소진)** 응답을 확인했습니다. 이번 확인은 실제 요청 1회에서 중단됐고 나머지 5개 요청·자동 재시도는 실행하지 않았습니다.
- **현재 실제 코드 생성은 API 잔액 보충 대기 상태이며 성공을 확인하지 않았습니다.** 키 설정과 안전한 오류 표시까지 확인했습니다. 잔액 보충 후 한 번의 실제 변환을 다시 검증해야 합니다. BRAIN 시뮬레이션도 미실행입니다.

- 로컬 개발 화면에 OpenAI API 키 연결·해제 기능을 추가했습니다. 입력한 키는 서버 메모리에서만 사용하며 서버를 재시작하면 해제됩니다. 배포 환경에는 설정 API를 등록하지 않습니다.
- 키 입력 영역을 오른쪽 위 **설정** 버튼의 별도 창으로 이동했습니다. Chrome에서 창 열기·닫기, Esc, 바깥 클릭, 닫을 때 미전송 키 삭제, 기존 모의 변환을 확인했습니다. 연결한 서버 키는 창을 닫아도 유지됩니다.
- 기존 서버의 `gpt-5-mini` 단일 모델 제한을 설정 창에 표시했습니다. 환경변수로 비싼 모델을 지정하면 호출 전 차단하고, 키 연결 요청의 모델 이름으로 이를 우회할 수 없음을 확인했습니다. 관련 공급자·로컬 키 연결 테스트 **25개 통과**, Ruff·JS 문법·diff 공백 검사 통과. 실제 API 호출은 수행하지 않았습니다.
- 로컬 주소·클라이언트·Origin 검사, 외부/프록시 요청 차단, 오류 응답의 키 비노출, 진행 중 키 변경 차단을 테스트했습니다.
- 화면에 모의/실제 AI 모드를 구분하고, 결과를 코드 변환 점검으로 표시했습니다. 모의 해석 일치도는 백분율 대신 ‘모의 값’으로 표시합니다.
- 실제 응답을 기다릴 수 있도록 브라우저 변환 대기시간을 65초로 변경했습니다.
- Python **141개 통과**, Ruff·브라우저 JS 문법·diff 공백 검사 통과. 별도 로컬 서버의 Chrome 자동화로 키 연결·해제, 새로고침 유지, 브라우저 저장소 미사용, 16초 지연 응답, 모바일 화면을 확인했습니다.
- 검증에는 테스트용 키와 API 응답 대역만 사용했습니다. 실제 OpenAI 호출 및 BRAIN 시뮬레이션은 아직 수행하지 않았습니다. 안내: [LOCAL_TEST.md](LOCAL_TEST.md).
- 사용자 선택에 따라 배포 목표를 **Vercel + Supabase**로 변경했습니다. 해당 구성으로 코드 이전 및 배포는 아직 수행하지 않았습니다. 아래 내용은 9월 23일의 기존 Cloud Run + Cloudflare 구현 기록입니다.

- strict JSON Schema·Pydantic 검증, 입력 크기 제한, 숫자·방향·거래량 조건 검사
- 전체 시뮬레이션 설정 12개, 설정 출처, 조건-코드 대응, 거부 사유 표시
- Cloudflare Access JWT 서명/발급자/대상/만료 검증 + 회원 이메일 목록
- 이메일·요청 ID·메서드·경로·본문을 포함한 Gateway HMAC
- SQLite Durable Object 트랜잭션 기반 월 50회·일 20회·분당 2회 제한
- 전역 동시 2건·월 1,000회, 작업별 비용 예약과 토큰 사용량 정산
- 회원별 24시간 중복 요청 재사용, 진행 조회, 만료 결과 삭제
- 남은 횟수, 운영진 집계, 회원별 추가 월간 한도, 운영 일시 중단 설정
- Cloud Run 준비/배포 스크립트, Worker 배포 설정, CI 테스트
- 합성 한국어 회귀 100개 및 별도 실제 모델 평가 실행기

Gateway 테스트는 이메일 헤더 위조, 잘못된 JWT 대상·만료·회원, 운영진 접근, 임의 프록시 경로, 입력 크기, 동시 중복 요청, 전역 동시 제한, 월간/예산 차단, 공급자 오류, 재시작 후 기록 유지, 캐시 만료·삭제를 다룹니다. 외부 네트워크는 테스트 대역으로 처리했습니다.

로컬 Python 3.14에서는 기존 pytest-asyncio/Starlette의 폐기 예정 API 경고가 발생합니다. 테스트 실패는 없으며 CI와 컨테이너의 기준은 Python 3.12입니다.
