# 필드 카탈로그 기반 변환 검증 · 2026-11-03

보고된 필드명 오류 9건·자료형 오류 4건·괄호 인용 오류 1건의 원인을 수정했습니다. 최종 수정본으로 새로운 전략 5건을 실제 OpenAI로 변환하고 생성식을 수정하지 않은 채 WorldQuant BRAIN 시뮬레이션에 전달했습니다. 알파 제출은 하지 않았습니다.

## 변경과 검증 범위

- 계정의 291개 데이터셋을 발견해 각 첫 50행을 조회하고 같은 계정에서 당일 확보한 상세 스냅샷을 합쳐 수치 필드 14,190개를 준비했습니다. 계정 전체 필드의 완전한 목록이라는 뜻은 아닙니다. 범위는 EQUITY/USA/TOP3000/Delay 1입니다.
- 영문 검색어 정리와 임베딩 검색으로 실제 후보를 찾고, 최대 12개 후보와 기본 필드를 응답 enum·서버 검증에 함께 적용합니다. 지표와 필드를 연결하는 고정 답안표는 없습니다.
- VECTOR는 `vec_avg` 후 시계열·순위·비율 연산을 적용합니다. 비교 필드와 조건식도 같은 목록·자료형·연산자 권한을 검사합니다.
- 원문 괄호·공백·바깥 따옴표 차이를 처리하며 실제 위치와 중복 검사는 유지합니다. 짧은 입력에서는 독립 절만 근거 enum으로 제공해 카탈로그 설명이나 공통 전체 문장을 잘못 인용하지 않도록 했습니다.
- 검색·임베딩·생성을 합친 최대 비용을 기존 34원 예약 안에 둡니다. 후보 수·부가 설명·출력 길이를 제한하며 자동 유료 재시도는 없습니다.
- 실제 실험은 운영과 동일한 `HarnessService`를 사용했습니다. 운영 HTTP 회원 세션·사용량 원장과 분리된 검증이며, 미승인 사용자의 운영 접근을 허용한 것이 아닙니다. 회원·작업·예산·비용 DB와 SQL은 변경하거나 초기화하지 않았습니다. Cloudflare Tunnel·DNS도 변경하지 않았습니다.

코드 생성 5/5 통과, 시뮬레이션 완료 5/5. `COMPLETE`는 필드·자료형 오류 없이 실행이 끝났다는 뜻이며 수익성이나 BRAIN 제출 심사 통과를 뜻하지 않습니다. Sharpe·Fitness·커버리지 등의 품질 검사는 별도로 확인해야 합니다.

ROE는 실제 목록의 Return on Equity 필드, PER은 연평균 배수 데이터가 선택됐습니다. 뉴스 사례는 헤드라인 긍정 점수와 뉴스 종합 감성의 21일 평균입니다. 편향 조정 목표주가 VECTOR의 평균을 종가로 나눈 비율을 사용했습니다. 옵션은 카탈로그 설명이 Infinite implied option volatility인 필드와 `returns`의 20일 표준편차를 사용했습니다. 기간·옵션 지표 종류 등 원문에 없는 데이터 선택은 AI 초안의 가정입니다.

개발 중에는 전역 목록의 10,000행 제한, 긴 후보 목록에 따른 출력 오류, 공통 원문 인용의 중복을 추가로 발견해 수정했습니다. 이전 실패와 진단 실험도 로컬에 보존했습니다. 또한 실행 완료 응답에 포함된 목표주가 비교의 단위 경고를 확인해, 서로 다른 데이터셋의 상대 비교는 비율을 우선하도록 지침을 수정했습니다. 비율 순위에서 불필요한 -1을 제거해 단위 불일치를 방지했고 순위·동점·업종 비교 결과가 같다는 수치 회귀 검사도 추가했습니다. 위 표는 이 수정 후 별도로 실행한 최종 5건이며 이전 성공만 골라 합산한 결과가 아닙니다.
