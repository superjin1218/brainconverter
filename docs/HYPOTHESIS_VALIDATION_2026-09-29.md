# 운영 가설 변환 확인 · 2026-09-29

PR #4의 선호 방향 검사 배포 후, 로그인된 운영 UI에서 실제 OpenAI 변환을 2회와 3회로 나누어 실행했습니다. 각 사례는 한 번 호출했고 자동 재시도는 없었습니다. 아래는 실행 당시 출력과 수동 의미 검토입니다. 문서 작성에는 새 AI 호출을 하지 않았습니다.

다섯 건 모두 코드가 생성됐고 선택한 대리 지표의 기본 점수 방향은 가설과 부합했습니다. 이 결과는 전체 자연어 해석 정확도, BRAIN 실행 성공, 알파 수익성이나 개선안의 품질을 보장하지 않습니다.

## 사례 1

> 같은 업종 애들은 다 올랐는데 혼자 못 오른 애가 따라갈 것 같아.

```text
(1 - group_rank(((close / ts_delay(close, 21)) - 1), industry))
```

같은 산업 내 최근 21거래일 수익률이 낮을수록 높은 점수: 이전의 방향 반전 수정. 21일은 AI가 정한 대리 기준.

## 사례 2

> 아침엔 별로였는데 장 끝날 때 힘이 세진 주식이 좋아 보여.

```text
rank((close - open))
```

시가 대비 종가 상승 폭이 클수록 높은 점수: 원치 않은 과거 모멘텀/벌점 없음. 절대 가격 차이 대리 지표로 가격 수준의 영향이 있고 장중 경로 전체를 확인하는 것은 아님.

## 사례 3

> 평소엔 조용했는데 갑자기 거래가 몰리는 주식이 눈에 들어와.

```text
rank(((volume / ts_mean(volume, 21)) - 1))
```

기본 코드 방향 일치: 당일 거래량이 21일 평균보다 많이 늘수록 높은 점수. 21일은 AI 가정.

## 사례 4

> 사람들이 몰리는데 가격은 아직 별로 안 오른 주식이 좋겠어.

```text
(rank(((volume / ts_mean(volume, 21)) - 1)) + (1 - rank(((close / ts_delay(close, 21)) - 1))))
```

기본 코드 방향 일치: 상대 거래량은 높을수록, 21일 수익률은 낮을수록 선호. 동일 가중치 점수 합이라 두 조건을 모두 만족해야 하는 엄격한 필터는 아님. 수정 선택지는 서로 유사함.

## 사례 5

> 장중에 올랐다가 다 토해낸 주식은 피하고 싶어.

```text
rank((close - high))
```

기본 코드 방향 일치: 종가-고가가 0에 가까울수록 선호하므로 고점 대비 하락이 큰 종목은 낮은 점수. 절대 가격 차이라 가격 수준의 영향을 받고 장중 경로 전체는 확인하지 않음. 수정 선택지 제목 두 개는 원래 의도와 반대로 표현됨.

## 다듬기 선택지에서 발견한 문제

사례 4의 선택지 제목은 ‘수급 강세 + 저상승’과 ‘거래량 확대 + 가격 후행’이었고, 설명도 실질적으로 비슷했습니다. 선택지가 서로 다른 개선 방향을 제공하는지 충분히 검사하지 못하고 있습니다.

사례 5의 제목과 실제 입력된 수정 전략은 다음과 같았습니다. 선택지만 클릭해 입력을 확인했으며 추가 AI 변환은 하지 않았습니다.

| 선택지 제목 | 클릭 후 입력된 전략 |
| --- | --- |
| 장중 고점 대비 종가 강한 종목 제외 | close와 high의 차이를 사용해 종가가 고가에 더 가까운 종목을 선호하도록 정리한다. |
| 장중 반납이 적은 종목만 회피 | close - high를 측정해 값이 덜 낮은 종목을 더 나쁘게 보지 않도록 설정한다. |

두 제목은 ‘고점 대비 하락이 큰 종목을 피한다’는 원래 방향과 반대로 읽힙니다. 기본 코드와 자연어 코드 설명의 방향이 맞아도 수정 선택지의 제목·설명·입력 전략은 별도 검증이 필요합니다. 이 문제는 아직 수정하지 않았습니다.

사용자가 알파 품질을 높이는 방향까지 확인했는지 질문했고, 체계적으로 검증하지 않았다고 답했습니다. 후속 검증에서는 제안 간 실질적인 차이, 원래 가설·명시 조건 보존, 변경 이유, 비교 실험과 예상 단점이 함께 제시되는지를 확인해야 합니다. 실제 성능 향상은 별도의 백테스트 대상입니다.

## 증빙과 검증 범위

- 선호 방향 검사 적용: [PR #4](https://github.com/blockcoder-sj/natural-language-brain-alpha-Converter/pull/4), 코드 `a1d1494`.
- 원본 JSON/화면: 로컬 Git 제외 `artifacts/intent-alignment-production.json`·`.png`, `artifacts/intent-additional-three-production.json`·`.png`.
- 코드·설명·가정·개선 제안·선택지 출력을 확인했습니다. 시뮬레이션이나 Alpha 제출은 수행하지 않았습니다.
- 21일 기간은 해당 입력에 명시되지 않은 AI 가정입니다. 가격 차이 지표는 종목 가격 수준의 영향을 받고, 일별 시가·고가·종가만으로 장중 경로 전체를 재현하지 못합니다.
- 여러 순위 점수의 합은 조건별 선호를 합친 것이며 각 조건을 모두 만족하는 엄격한 진입 필터와 다릅니다.
- 현재 자동 검사는 구조·근거·일부 명시 조건·계획에서 코드로 옮긴 방향을 검사합니다. AI가 원문의 뜻을 완벽히 해석했거나 개선 제안이 성과를 높인다는 증명은 아닙니다.
