# Muse 모델 변경 검증 범위와 월 비용

확인일: 2026-09-27. 사용 모델은 `meta/muse-spark-1.3-contributor`입니다. 아래 비용은 실제 사용 내역이 아닌 토큰 길이에 따른 추정입니다.

## 의도한 동작과 확인한 범위

자연어 전략 → SKILL.md 지침에 따른 AI 해석 1회 → 구조화된 JSON → Python의 원문 조건 검사·FASTEXPR 생성 → 코드와 BRAIN 설정 12개를 표시합니다. 승인된 회원만 변환할 수 있으며 여러 AI의 합의·자동 재시도·다른 모델 전환은 없습니다.

- Python 270개, 임시 PostgreSQL 역할·한도·대기열·비용 검증 23개(합계 293개), 프런트 상태 검증 23개 통과.
- 오프라인 모의 전략 100/100 통과. 이 수치는 Muse의 자연어 해석 정확도가 아닙니다.
- 실제 Supabase DB 마이그레이션·RLS·테이블/함수 역할 권한을 확인했습니다. 최초 운영자의 이메일 인증·approved/admin 상태와 누적 20,000원 제한 적용을 확인했습니다.
- Vercel Production 모델·인증 설정과 기존 Supabase 서버 Secret 저장을 확인했습니다.
- 모델 ID·Chat Completions 경로·최소 추론·출력 제한·JSON Schema 요청은 공식 문서와 비교했습니다. [Vercel 모델 안내](https://vercel.com/ai-gateway/models/muse-spark-1.3-contributor), [Gateway 추론 설정](https://vercel.com/docs/ai-gateway/models-and-providers/reasoning), [Meta 구조화 출력](https://dev.meta.ai/docs/structured-output).

2026-09-27 로컬에서 Meta 키를 Gateway에 보내던 인증 오류를 수정했습니다. `MUSE_API_PROVIDER=meta`로 Meta 공식 API에 직접 연결해 단순 하락 순위, 거래량 조건·산업 중립화 전략 2건이 성공했습니다. 단순 전략은 입력 817토큰·출력 160토큰, 앱의 반올림 비용 추정 $0.000114, 전체 처리 약 3.5초였습니다. 공급자 청구서를 확인한 금액은 아닙니다. 초기 실패 1회 포함 앱 예산 예약은 12원입니다.

**실제 Muse 성공 사례는 2건이며, 폭넓은 한국어 해석 정확도·부하 성능·배포 환경의 가입/승인/변환 연결은 아직 검증하지 않았습니다.** 두 사례로 모든 전략의 정확도를 보장하지 않습니다.

현재는 가격/수익률의 단일 신호, 일정 기간 가격 변화, 평균 대비 거래량 같은 필터와 중립화를 지원합니다. 복합 신호·재무 데이터·기간 수익률 계산·상위 N개 선정·이동평균 교차·손절/익절은 지원 범위 밖이며 거절해야 합니다. 모든 자연어 전략을 변환하는 프로그램은 아닙니다. PASS는 내부 변환 검사의 통과이며 BRAIN Simulate 성공이나 수익성을 뜻하지 않습니다.

## 월 1,000회 토큰 사용료

Contributor 요금은 입력 100만 토큰당 $0.10, 출력 100만 토큰당 $0.20입니다. Gateway는 토큰 요금에 별도 마크업이나 플랫폼 수수료를 붙이지 않습니다. [Meta 공식 요금](https://dev.meta.ai/docs/pricing-rate-limits), [Vercel Gateway 요금](https://vercel.com/docs/ai-gateway/pricing).

매회 모델 요청 1번, 캐시 할인 없음, 추가 도구/웹 검색 없음, 세금·환율·결제 처리 수수료 제외를 가정합니다. 입력에는 전략뿐 아니라 시스템 지침·응답 스키마가 포함됩니다. 출력 가정은 추론 토큰 등 청구되는 출력 전체를 포함한 값입니다.

| 1회 평균 입력 | 1회 평균 출력 | 월 1,000회 AI 사용료 |
| --- | --- | --- |
| 1,500토큰 | 300토큰 | $0.21 |
| 2,500토큰 | 500토큰 | $0.35 |
| 5,000토큰 | 1,024토큰 | $0.7048 |

계산식: `요청 횟수 × (평균 입력 토큰 × 0.10 + 평균 출력 토큰 × 0.20) / 1,000,000`.

짧은 실습 전략의 계획값은 대략 **월 $0.2~$0.7**입니다. 실제 토크나이저·추론량을 측정하지 않았으므로 상한 보장은 아닙니다. 실사용 1건의 usage를 확인한 뒤 평균 길이를 갱신해야 합니다. 길어진 입력, 모델 가격 변경, 수동 재요청은 비용을 바꿉니다.

프로그램은 출력 최대 1,024토큰, 회원별 월 50회/일 20회/분당 2회, 사이트 전체 월 1,000회/동시 20건으로 제한합니다. 실패 시도도 사이트 사용량에 포함하며 자동 추가 호출은 하지 않습니다. 요청 횟수 한도 외에 실제 Muse 시도당 4원씩 보수적으로 누적 예약하고 20,000원에서 자동 중지합니다. 월별 초기화는 없습니다. 실제 청구서나 계정 전체 결제 한도와 다르며 [계산과 범위](AI_BUDGET.md)를 확인하세요.

20건을 넘는 요청은 대기열에서 기다리며 화면을 열어 두면 순서대로 시작합니다. 같은 요청 ID를 5초마다 확인하는 동안 AI 호출·토큰 비용은 없습니다. 확인용 Vercel 요청과 Supabase DB 호출은 늘지만 월 1,000회 제한과 변환당 한 번 호출은 유지합니다. 따라서 같은 변환 횟수·토큰 길이면 AI 사용료는 같습니다. 호스팅 사용량과 비용은 별도로 관찰해야 합니다.

Contributor는 입력·응답의 Meta 학습 활용을 허용하는 대신 할인되는 요금입니다. 사이트에서 변환 전 동의를 받습니다. 비공개 전략을 학습에 제공하고 싶지 않다면 다른 요금 모델과 코드의 모델 제한을 함께 변경해야 합니다. [Meta Contributor 설명](https://dev.meta.ai/docs/pricing-rate-limits).

Gateway의 무료 $5 크레딧은 일부 모델에만 적용되므로 Muse가 자동 무료라고 가정하지 않습니다. 대상 모델·계정의 사용 권한 및 크레딧을 확인해야 합니다. 선충전 금액과 실제 월 소비액은 다를 수 있습니다. [Gateway 무료/유료 요금](https://vercel.com/docs/ai-gateway/pricing).

## 사이트 운영 비용

- Vercel Hobby·Supabase Free의 자격과 사용량 범위 안이면 호스팅/DB 기본료는 $0입니다. Hobby는 비상업적 개인 용도로 제한되므로 실제 동아리 운영 용도의 자격을 확인해야 합니다. [Vercel Hobby](https://vercel.com/docs/plans/hobby), [Supabase 요금](https://supabase.com/pricing).
- Supabase Free는 1주간 활동이 없으면 일시 정지합니다. 9월 30일 이후 10월 28일까지 세션을 쉬는 동안 이용이 없으면 수동 재개가 필요할 수 있습니다. 계속 이용 가능하게 유지하려면 Pro 등 중지되지 않는 운영 조건을 검토해야 합니다. Pro는 첫 기본 프로젝트 기준 $25/월부터입니다. [Supabase 요금](https://supabase.com/pricing).
- 따라서 무료 호스팅 범위에서는 AI 비용만 위 추정치가 더해지며, Supabase Pro 기본료를 포함하면 약 $25.2~$25.7/월입니다. Vercel 유료 플랜·사용량 초과·메일 서비스·도메인 비용은 별도입니다. 유료 업그레이드나 결제는 실행하지 않았습니다.
- 일반 회원의 이메일 인증에는 Custom SMTP가 필요합니다. 현재 기본 메일은 Supabase 조직 팀 계정에만 보낼 수 있어 일반 회원 운영 준비가 끝난 상태가 아닙니다. [Supabase SMTP 안내](https://supabase.com/docs/guides/auth/auth-smtp).

## 실제 운영 전 확인 순서

1. Custom SMTP를 설정합니다. 최초 운영자의 이메일 인증·권한은 이미 확인했습니다.
2. 현재는 Meta 발급 키와 `MUSE_API_PROVIDER=meta`로 직접 호출합니다. Gateway를 선택할 때만 Vercel 발급 키 또는 OIDC를 사용합니다. 기존 OpenAI 키로 Muse를 호출하지 않습니다.
3. 실제 전략 1건부터 호출해 JSON 응답·생성 코드·응답 지연·usage를 확인합니다. 자동 대량 평가는 하지 않습니다.
4. 기간·방향·비교 연산자·거래량 필터·중립화별 소수의 대표 사례와 지원 밖 전략 거절을 확인합니다.
5. 배포 환경에서 미승인 회원 차단·승인 후 변환·이용 중지 후 차단·중복 요청 결과 재사용을 확인합니다.
6. 생성된 FASTEXPR를 BRAIN에서 사용자가 직접 실행해 문법·설정 호환을 확인합니다.

현재 Meta 직접 호출 2건은 성공했고, 배포·BRAIN 실행은 하지 않았습니다. 설정 절차는 [VERCEL_SUPABASE_SETUP.md](VERCEL_SUPABASE_SETUP.md)를 따릅니다.
