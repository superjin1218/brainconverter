## 현재 해석·검증 경계

- 이번 보완은 `entry.condition`을 별도 AST 비교식으로 검증한 뒤 점수와 합칩니다. 조건 조각이 괄호·쉼표로 추가 점수 항을 삽입하는 것을 거부합니다. ‘TOP3000 주식’, ‘매일 주가’에서 기간을 만들어내던 정규식도 수정했습니다.
- OpenAI → `IntentIR` → 원문 근거/선호 방향 검사 → FASTEXPR + 설정 12개 + 자연어 설명의 흐름입니다.
- `chat_provider.py`는 새 응답을 `IntentIR`로만 파싱합니다. 구형 `DraftIR`·`StrategyIR`은 저장 응답과 오프라인 호환용이며, 운영 실패 시 구형 템플릿으로 대체하지 않습니다.
- AI는 최대 3개 측정 기준과 필요한 거래 조건을 정합니다. `intent_compiler.py`가 원문에 없는/겹치는 근거, 중복 측정값, 명시한 동종업계 비교 누락을 검사합니다.
- 서버가 `rank`/`group_rank`와 `higher`/`lower` 방향을 적용하고 양수 가중치로 합칩니다. 독립 AST 해석기로 다른 측정값을 고정하고 하나를 변화시켜 컴파일된 점수의 방향을 확인합니다.
- `draft_compiler.py`는 허용 AST·함수·인자와 명시한 숫자·일부 데이터·수익률 기간·거래량 비교 조건을 검사합니다. 코드 설명과 가정은 계획과 코드에서 생성합니다.
- 이 검사는 **계획→코드의 방향**을 확인합니다. **원문→계획의 모든 의미 해석**을 증명하지 않습니다. 가설별 대리 지표 선택이 여전히 중요합니다.
- 재무·뉴스 데이터와 손절·익절·보유 기간 주문 실행은 지원하지 않습니다. `trade_when(..., ..., -1)`은 조건 미충족 시 직전 값을 유지하며 자동 청산하지 않습니다.
- BRAIN 로그인·Simulate·Alpha 제출을 자동 실행하지 않습니다. 수익성·실행 성공은 미검증입니다.

## 실제 AI 검증과 미완료 사항

선호 방향 검사 배포 후 운영 UI에서 **총 5회(2회+3회)** 변환했습니다. 각 요청은 AI 1회이고 자동 재시도는 없습니다. 원문·실제 코드·판정은 [검증 기록](HYPOTHESIS_VALIDATION_2026-09-29.md)에 정리했습니다.

- 기존 오답 두 건: 업종 내 뒤처진 종목 추격 → 업종 내 낮은 과거 수익률 선호, 장중 회복 → `rank(close - open)`. 반대 방향과 불필요한 모멘텀/벌점 문제가 해당 재검사에서 해소됐습니다.
- 추가 세 건: 평소 대비 거래량 급증, 거래량 증가+낮은 과거 수익률 조합, 장중 상승분 반납 회피. 모두 생성됐고 대리 지표의 기본 점수 방향은 가설과 부합했습니다.
- **미해결:** 거래량 증가+가격 부진의 수정 선택지 두 개가 서로 비슷합니다. 상승분 반납 회피의 선택지 제목은 ‘종가 강한 종목 제외’, ‘반납이 적은 종목만 회피’로 원문·코드와 반대로 나왔습니다. 실제 선택지 클릭 후 입력 전략도 확인했으며 재변환은 실행하지 않았습니다.
- 사용자가 ‘좋은 알파가 되도록 방향을 제시하는지도 검증했는가’를 물었고, **개선안의 품질은 체계적으로 검증하지 않았음**을 분명히 답했습니다. 서로 다른 개선 방향인지, 원래 가설을 유지하며 무엇을 왜 바꾸는지, 비교 실험과 예상 단점을 제시하는지 추가 검증이 필요합니다. 개선 효과를 백테스트로 확인하지 않았습니다.
- 후속 방향은 선택지의 제목·설명·수정 전략 사이의 의미 일치, 제안 간 실질적인 차이, 개선 실험의 구체성입니다. 아직 이 후속 구현을 완료한 것으로 기록하거나 설명하면 안 됩니다.
- 절대 가격 차이는 가격 수준의 영향을 받으며 장중 경로 전체를 확인하지 않습니다. 여러 순위의 합은 모든 조건을 동시에 충족해야 하는 필터와 다릅니다.
